# Каллиграф для Android

Облегчённая версия для телефона: машина подключается к телефону кабелем через OTG-переходник.

- **Писать** — текст на листе A4 или в тетради, выбор почерка и размера, «Начать со строки», заготовки текстов,
  ввод голосом, текст с фото (распознавание без интернета), проверка без чернил, обводка границ,
  продолжение после обрыва.
- **Почерки** — свой почерк по фото заполненного шаблона, рисованием пальцем или из файла (.ttf, .kfont с компьютера).
- **Пульт** — стрелки, ручка вверх/вниз, «Здесь начало листа», «В начало», «Разблокировать», «Поменять верх/низ»,
  тема, крупный шрифт, звук и вибрация.

## Установка
1. Скачайте `Kalligraf.apk` из раздела **Releases** и откройте файл на телефоне.
2. Разрешите установку из этого источника. Play Защита может предупредить, что приложение не из магазина —
   нажмите «Всё равно установить».
3. Подключите машину через OTG-переходник и разрешите доступ к USB.

Поддерживаются платы на CH340/CH341 и Arduino с CDC-портом.

## Сборка
Нужны Android SDK (build-tools, platform android-34) и JDK 11+. Gradle не нужен.

```powershell
powershell -ExecutionPolicy Bypass -File build.ps1
```

Скрипт собирает телефонный интерфейс (`vite.mobile.config.ts`), кладёт его в APK, компилирует Java-мост USB
и подписывает файл. Ключ `kalligraf.keystore` создаётся при первой сборке. Результат: `android/Kalligraf.apk`.
