# Каллиграф

Программа для робота-писателя (плоттера на GRBL, например GUANGKU): пишет текст «от руки» ручкой на бумаге.

- **Версия для компьютера** — открывается в браузере, ничего устанавливать не нужно:
  **https://kalygulovdonat-ctrl.github.io/kalligraf/**
  Нужен Google Chrome, Microsoft Edge, Opera или Яндекс.Браузер (в них есть доступ к USB).
- **Версия для Android** — файл `Kalligraf.apk` в разделе [Releases](../../releases).

## Возможности
- Текст рукописными шрифтами с кириллицей и кыргызскими буквами, «живой» почерк, тетрадь в клетку, A4 и свои форматы,
  многостраничность с паузой «положите новый лист».
- Свой почерк: по фото заполненного шаблона или рисованием на экране; импорт обычного .ttf.
- Формулы, QR-коды, чертёжный шрифт и рамка по ГОСТ, рисунки (лабиринты, судоку, графики, орнаменты), импорт SVG,
  перевод фото в рисунок.
- Предпросмотр с анимацией, оптимизация маршрута, обводка границ, продолжение после обрыва.
- Пульт: перемещение ручки, начальная точка, высота ручки, консоль G-кода.
- Симулятор — можно попробовать без машины.

## Первое подключение
1. Подключите машину USB-кабелем и включите питание. Закройте другие программы, которые занимают порт.
2. «Подключить машину» → «По USB-кабелю» → выберите порт (обычно *USB-SERIAL CH340*).
   Если порта нет — установите драйвер CH340 и переподключите кабель.
3. Пройдите мастер настройки, затем в «Пульте» поставьте ручку в левый верхний угол листа и сделайте эту точку началом.

## Для разработчиков
```
npm install
npm run dev          # http://localhost:5173
npm run build        # сборка в dist
npm test
npm run dev:mobile   # телефонный интерфейс
```
Android-приложение — в папке [`android`](android).

Рукописные шрифты — Google Fonts под лицензией SIL OFL, исходники и лицензии в `fonts-src/`.
